# Security Policy

## Supported versions

Security fixes are accepted against the latest `main` branch release candidates.

## Reporting a vulnerability

Please open a private security advisory on GitHub, or email the maintainers listed in the repository if advisories are unavailable.

Include:

- a clear description of the issue
- reproduction steps
- affected browsers / platforms
- impact assessment if known

Do not file public issues for unpatched vulnerabilities.

## Scope notes

AutoSkip must not bypass DRM, authentication, geographic controls, or paid access restrictions. Reports that require such bypasses are out of scope.
